1 Introduction and Objective

In the last two lectures we stored a graph in an adjacency list or an adjacency matrix. In this tutorial we use that structure to visit every vertex of a graph, with the two standard traversals: Breadth-First Search (BFS) and Depth-First Search (DFS). The aim is to be able to run both by hand, to say what each one costs, and to recognise a problem that one of them solves.

Attempt every question before the tutorial. Q1 to Q3 are routine and will only be checked quickly; most of the hour goes to Q4 to Q6. Unless a question says otherwise, a traversal that has a choice of neighbours takes them in alphabetical order.

Standard Stuff

Q1). Run BFS on G from source vertex A.
  1. (a) List the vertices in the order in which BFS visits them.
  2. (b) For every vertex, give its distance from A, counted in edges.
Q2). Now run the recursive DFS on G from source vertex A.
  1. (a) List the vertices in the order in which DFS first visits them.
  2. (b) G has 8 edges. Which of them are not edges of the DFS spanning tree that this run produces?
