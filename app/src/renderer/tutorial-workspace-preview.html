Graph traversal

Learning overview
  1. Search foundations
  2. Breadth-first search

Search foundations

A graph contains vertices and edges. A search starts at one vertex and visits connected vertices in an order set by its frontier.

Source: sample lecture · p. 1–2

Breadth-first search

Breadth-first search visits vertices in increasing distance from the start. A FIFO queue holds the next frontier; a visited set prevents repeated work.

Source: sample lecture · p. 3–4

Comparing strategies

Depth-first search follows one path as far as possible before returning. Breadth-first search explores one distance layer at a time, which matters when an unweighted shortest path is needed.

Source: sample lecture · p. 5–6
